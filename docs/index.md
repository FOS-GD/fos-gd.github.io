# Welcome to FOS-GD

This site is built from plain Markdown files in the `docs/` folder.

- Edit this page in `docs/index.md`.
- Add a new page by creating another `.md` file in `docs/` — it shows up in the menu automatically.
- Link to other pages with their Markdown filename, e.g. [About](about.md).

!!! note
    Admonitions like this one work too, just like in MkDocs.
